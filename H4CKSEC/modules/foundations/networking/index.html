Networking Fundamentals

Core networking concepts required for cybersecurity: models, addressing, protocols and security implications.

BeginnerOverview

A solid understanding of networking is foundational for almost every cybersecurity discipline — offensive and defensive. This module covers the models, addressing, common protocols and the security considerations that appear repeatedly in assessments and operations.
